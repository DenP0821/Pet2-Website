Этот многостраничный проект создан после более углублённого знакомства с HTML, CSS, JavaScript. :information_desk_person:  

На этот раз я решил написать всю структуру, стили и логику без библиотек-помощников. Исключение составил лишь Swiper (классная библиотека :sunglasses:).  

Я тщательно продумал идею сайта, его наполнение. Исходил как с позиции контент-мейкера, так и (что более важно) с позиции того, насколько мне тот или иной функционал поможет с накоплением практического опыта. :thumbsup:

Отдельное время было отведено для сравнения и компоновки цветовой палитры. Как для светлой, так и для тёмной темы. Очень хотелось, чтобы сайт выглядел презентабельно настолько, насколько это возможно с нынешним опытом. :blush:  

В процессе написания этого пет-проекта я окончательно понял, что меня не просто привлекает Frontend, я начал :fire:гореть:fire: этим.

<hr/>

В данном проекте реализовано:

:one: Адаптивность для различных размеров экрана;

:two: Навигация для больших экранов - панель с красивым ховер-эффектом при наведении на элементы навигации. Навигация для малых экранов - полупрозрачное "выкатывающееся" меню с анимированными бургер-кнопкой и элементами списка;

:three: Переключение между светлой и тёмной темами посредством стилизованного тумблера в навигационной панели. Выбранная тема запоминается c помощью localStorage;

:four: Картинки хедера главной страницы на малых экранах скомпонованы с помощью библиотеки SwiperJS;

:five: Кнопка прокрутки страницы к началу;

:six: Галерея изображений после главной информации основной страницы с возможностью просмотреть кажое изображение и подпись в отдельном модальном окне;

:seven: Как при открытии меню для малых экранов, так и при открытии модального окна галереи - отключена прокрутка страницы и затемнён фон;

:eight: Cтилизованы в виде блоков как информация на главной странице, так и на странице с историей рок-музыки;

:nine: Реализована заметочная в виде toDo-листа с возможностью добавлять, помечать выполненными и удалять элементы. Данные сохраняются в localStorage. Предусмотрен запрет на добавление пустых заметок/с пробелами в начале. Об этом уведомляют всплывающие баннеры-алерты (с помощью setTimeout);

:keycap_ten: Реализована "фейковая" страница авторизации: Поля ввода логина и пароля с функцией показа/скрытия пароля (чекбокс). Запрет на авторизацию с пустыми полями (баннер-алерт). Работа с регулярными выражениями для проверки правильности ввода логина/пароля (при неверном вводе всплывают подсказки). Если ввод в обоих полях успешен - после нажатия на кнопку происходит окрашивание полей в зелёный цвет и перенаправление на главную страницу.
